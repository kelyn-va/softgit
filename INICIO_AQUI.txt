🔌 API ENDPOINTS
═════════════════

  GET /reportes
  └─ Carga la vista principal

  GET /api/reportes/inventario
  └─ Obtiene datos de inventario

  GET /api/reportes/ventas
  └─ Obtiene datos de ventas

  GET /api/reportes/ventas-categoria
  └─ Agrupa ventas por categoría

  GET /api/reportes/ventas-empleado
  └─ Agrupa ventas por empleado

  GET /api/reportes/tendencia-ventas
  └─ Obtiene tendencia diaria

  GET /api/reportes/stock-bajo
  └─ Identifica stock bajo

🎓 EJEMPLOS DE USO
═══════════════════

  Ver inventario filtrado por categoría:
    1. Selecciona "Inventario"
    2. Elige una categoría
    3. Haz clic en "Aplicar Filtros"
    4. Ves la tabla con productos de esa categoría

  Ver tendencia de ventas:
    1. Selecciona "Tendencia de Ventas"
    2. Selecciona rango de fechas
    3. Haz clic en "Aplicar Filtros"
    4. Ves gráfico de línea con tendencia diaria

  Ver eficiencia de vendedor:
    1. Selecciona "Ventas por Empleado"
    2. Selecciona rango de fechas
    3. Haz clic en "Aplicar Filtros"
    4. Ves gráfico de barras comparando vendedores
